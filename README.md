# ABBOUTE — Groupe

Site vitrine du groupe **ABBOUTE** pour **abboute.com**.

Un groupe familial multi-secteurs, deux entités :
- **ABBOUTE Europe** (Pologne) — Technologie, Communication
- **ABBOUTE El Djazaïr** (Algérie) — Construction, Restauration, Automobile, Agroalimentaire, Achat multi-pays

Site statique, sans build, sans dépendances. HTML / CSS / JS.
